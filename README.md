# Healthy Food Store 🛒

Bienvenido al repositorio de Healthy Food Store, una tienda online para la compra de productos saludables. Este e-commerce ofrece una experiencia de usuario con carrito de compras y gestión de productos por categorías.

## Características 🌟

- **Catálogo de productos por categorías** (Frutas, Verduras, Panadería, Mariscos, Lácteos, Snacks)
- **Carrito de compras dinámico** con contador en tiempo real
- **Sistema de gestión de productos** (agregar, incrementar/decrementar cantidades, eliminar)
- **Mapa interactivo de contacto** con Leaflet
- **Formulario de contacto**
- **Banners y sliders promocionales**

## Tecnologías Utilizadas 💻

Este proyecto está construido utilizando las siguientes tecnologías y bibliotecas:

- **Vue.js 3**: Framework principal para la construcción de la aplicación.
- **Vuex**: Para la gestión del estado global (carrito, productos, categorías).
- **Vue Router**: Para la navegación entre vistas.
- **TailwindCSS**: Framework de CSS para estilos modernos y responsivos.
- **FontAwesome**: Iconos para la interfaz.
- **Axios**: Para el consumo de datos desde archivos JSON.
- **Leaflet / Vue3-Leaflet**: Para el mapa interactivo en la página de contacto.
